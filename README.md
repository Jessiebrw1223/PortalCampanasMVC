# PortalCampanasMVC

Proyecto base en ASP.NET Core MVC (.NET 8) para la práctica calificada de campañas comerciales.

## Funcionalidades incluidas
- Listado de campañas
- Detalle de campaña
- Filtro por categoría y estado
- Resumen en memoria
- Layout con navegación

## Ejecutar
```bash
dotnet restore
dotnet run
```
